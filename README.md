# UPSCChatbot

This repository contains a small command-line chatbot that can answer a few common questions about the UPSC Civil Services Examination.

## Requirements

- Python 3.6 or later

No additional packages are required since the project only uses Python's standard library.

## Usage

Run the chatbot interactively:

```bash
python chatbot.py
```

Type your question and the bot will respond. Enter `exit` or `quit` to end the session.

## Testing

Run the unit tests with:

```bash
python -m unittest
```
